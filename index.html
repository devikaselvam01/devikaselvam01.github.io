About

I spent eight years as a software engineer before returning to study, and completed an M.Sc. in Computer Science at the University of Freiburg (2020–2026). My work centers on learning-based perception for robotics: asking when vision models and foundation models can be trusted, and testing it with careful experiments. I also enjoy automated machine learning, and I won the large-network track of the university’s deep learning competition in 2025.

Research

Master’s thesis · 2026

Industrial Part Classification Using LiDAR Scans

Built a robot-arm data collection setup (ROS, LiDAR) and compared point cloud and image classifiers across lighting conditions. Under unseen lighting, the best point cloud model kept 94.9% accuracy while the best image model fell from 95.3% to 77.6%.

Master’s project · 2025/26

Affordance Learning from Static Images

A zero-shot pipeline that uses a vision-language model to find door parts and derive 3D manipulation trajectories, without demonstrations. Metric depth was the dominant factor for accuracy.

Code on GitHub

AutoML project · 2024

Meta-Learning with TabPFN

Predicts the best model family for unseen tabular datasets from 31 meta-features, then tunes it automatically, in about five minutes of compute.

Deep learning lab

Knowledge Distillation Beyond Model Compression

A team study of nine distillation methods on CIFAR-100, finding that distillation improves generalization even with a large teacher–student gap.
